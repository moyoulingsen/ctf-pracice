# CTF 工具清单

## 当前环境

- Windows 11：桌面工具、浏览器、抓包、逆向 GUI。
- WSL2 Ubuntu 24.04：Linux 命令行工具、Python 脚本、Pwn 调试环境。
- Docker Desktop：后续复现题目环境、运行靶场服务。
- Java/OpenJDK 25：运行 Ghidra 等 Java 工具。

## Windows 桌面工具

| 工具 | 方向 | 用途 | 常见用法 |
|---|---|---|---|
| Burp Suite Community | Web | 抓包、改包、重放 HTTP 请求 | 浏览器代理到 Burp，使用 Proxy / Repeater 分析请求 |
| Wireshark | Misc / 流量分析 | 打开 `.pcap` / `.pcapng` 流量包，分析网络通信 | 过滤 `http`、`tcp`、`dns`，右键 Follow TCP Stream |
| Npcap | Wireshark 依赖 | Windows 抓包驱动 | 安装后 Wireshark 才能实时抓包 |
| Ghidra | Reverse | 反编译 ELF/EXE，查看伪代码和汇编 | 新建 Project，导入程序，Analyze 后看 Decompiler |
| ImHex | Misc / Reverse | 十六进制编辑、文件结构分析 | 打开未知文件，查看魔数、偏移、隐藏数据 |
| HxD | Misc | 轻量十六进制编辑器 | ImHex 备用工具，快速查看和修改二进制 |
| VSCode | 通用 | 写 Python 脚本、整理笔记、连接 WSL | 在 WSL 目录运行 `code .` |
| 7-Zip | Misc | 解压各种压缩包 | 解压 zip/rar/7z/tar/gz 等题目附件 |

## WSL 命令行工具

| 工具 | 方向 | 用途 | 示例 |
|---|---|---|---|
| `file` | Misc / Reverse | 判断文件类型 | `file chall` |
| `strings` | Misc / Reverse | 提取可见字符串 | `strings chall | less` |
| `xxd` | Misc / Crypto | 十六进制查看 | `xxd file.bin | less` |
| `binwalk` | Misc | 查找文件中隐藏的压缩包/固件 | `binwalk -e image.png` |
| `exiftool` | Misc | 查看文件元数据 | `exiftool image.jpg` |
| `steghide` | Misc | 图片/音频隐写提取 | `steghide info a.jpg` |
| `foremost` | Misc | 文件恢复 | `foremost dump.bin` |
| `nc` | Pwn / Web | 连接远程题目服务 | `nc host port` |
| `nmap` | Web / Misc | 端口和服务探测 | `nmap -sV host` |
| `ffuf` | Web | 目录、参数、子域爆破 | `ffuf -u http://target/FUZZ -w wordlist.txt` |
| `gobuster` | Web | 目录爆破 | `gobuster dir -u http://target -w wordlist.txt` |
| `sqlmap` | Web | SQL 注入自动化测试 | `sqlmap -u "http://target/?id=1"` |
| `gdb` | Pwn / Reverse | Linux 程序调试 | `gdb ./pwn` |
| `pwndbg` | Pwn | GDB 增强插件 | 装好后运行 `gdb ./pwn` 自动加载 |
| `checksec` | Pwn | 查看程序保护 | `checksec ./pwn` |
| `ROPgadget` | Pwn | 查找 ROP gadget | `ROPgadget --binary ./pwn` |
| `pwntools` | Pwn | 写利用脚本 | `from pwn import *` |
| `radare2` | Reverse | 命令行逆向分析 | `r2 -A ./chall` |
| `ltrace` | Reverse / Pwn | 跟踪库函数调用 | `ltrace ./chall` |
| `strace` | Reverse / Pwn | 跟踪系统调用 | `strace ./chall` |
| `john` | Crypto / Misc | 爆破 hash 或压缩包密码 | `john hash.txt` |
| `hashcat` | Crypto / Misc | hash 爆破 | `hashcat -m 模式 hash.txt wordlist.txt` |

## 建议工作流

### Web

1. 浏览器访问题目。
2. Burp Suite 抓包。
3. Repeater 重放和修改请求。
4. WSL 用 `ffuf`、`sqlmap` 辅助测试。
5. Python `requests` 写自动化脚本。

### Crypto

1. 读题目源码和输出。
2. 判断是编码、古典密码、RSA、AES，还是数论问题。
3. 在题目目录写 `solve.py`。
4. 优先使用 `pycryptodome`、`gmpy2`、`sympy`。

### Reverse

1. `file chall` 判断架构。
2. `strings chall` 找明显 flag 或提示。
3. Ghidra 导入并反编译。
4. 必要时用 `gdb` / `ltrace` 动态分析。

### Pwn

1. `file ./pwn` 判断程序类型。
2. `checksec ./pwn` 查看保护。
3. `gdb ./pwn` 调试。
4. `ROPgadget --binary ./pwn` 找 gadget。
5. 用 `pwntools` 写 `exp.py`。

### Misc

1. `file` 判断类型。
2. `strings` 找文本。
3. `exiftool` 看元数据。
4. `binwalk` 找隐藏文件。
5. Wireshark 分析流量包。
6. ImHex/HxD 查看二进制结构。
