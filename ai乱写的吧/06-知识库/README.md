# CTF 知识库总览

这个目录按 CTF 常见方向整理知识点，顺序是由浅入深。建议先建立基础方法论，再按方向刷题。

## 推荐学习顺序

### 第一阶段：通用基础

目标：能看懂题目附件，会用基础工具分析文件，会写简单 Python 脚本。

需要掌握：

- Linux 基础命令：`cd`、`ls`、`file`、`strings`、`xxd`、`grep`。
- Python 基础：字符串、bytes、列表、字典、文件读写。
- 编码基础：Base64、Hex、URL 编码、ASCII。
- 浏览器开发者工具基础。
- VSCode + WSL 工作流。

### 第二阶段：Misc + Crypto

原因：这两个方向最适合入门，反馈快，能快速熟悉工具和脚本。

学习：

- [misc/README.md](misc/README.md)
- [crypto/README.md](crypto/README.md)

重点：

- 文件类型识别。
- 图片隐写。
- 流量包基础。
- 编码转换。
- XOR。
- RSA 基础。
- AES 基础。

### 第三阶段：Web

原因：Web 题实战感强，需要理解 HTTP 和服务端逻辑。

学习：

- [web/README.md](web/README.md)

重点：

- Burp Suite 抓包。
- HTTP 请求和响应。
- Cookie / Session。
- SQL 注入。
- 文件上传。
- 文件包含。
- 命令执行。
- SSRF。

### 第四阶段：Reverse

原因：逆向需要理解程序结构和反编译工具。

学习：

- [reverse/README.md](reverse/README.md)

重点：

- `file`、`strings`。
- Ghidra 基础。
- 找 main。
- 找字符串交叉引用。
- 识别比较逻辑。
- 写 Python 还原算法。

### 第五阶段：Pwn

原因：Pwn 门槛最高，需要 C、汇编、调试、内存基础。

学习：

- [pwn/README.md](pwn/README.md)

重点：

- C 语言危险函数。
- 栈结构。
- `checksec`。
- gdb 调试。
- 栈溢出。
- ret2text。
- ret2libc。
- pwntools。

## 每道题的记录格式

建议每道题都写一个 `README.md`：

```markdown
# 题目名

## 信息

- 平台：
- 方向：
- 难度：
- 日期：
- 附件：

## 题目描述

原题描述。

## 分析过程

记录关键命令、截图、发现点。

## 解题脚本

说明 `solve.py` 或 `exp.py` 的作用。

## Flag

```text
flag{...}
```

## 复盘

- 学到什么？
- 卡在哪里？
- 下次遇到类似题怎么做？
```

## 入门做题原则

1. 不要只看题解，要先自己尝试 20-40 分钟。
2. 看题解时重点看思路，不要只复制 payload。
3. 每做完一题，记录“识别点”和“关键命令”。
4. 不要一开始追求难题，先把基础题刷熟。
5. 每个方向都可以尝试，但主线建议先 Misc/Crypto/Web。

## 硬核成长路线

如果目标不是“会做几道入门题”，而是成为能稳定打比赛的选手，建议按 6 个阶段推进。

### 阶段 1：计算机底层基础

目标：看懂程序怎么运行、数据怎么表示、网络怎么通信。

必修内容：

- C 语言：指针、数组、结构体、内存布局、函数调用。
- Linux：文件权限、进程、管道、重定向、环境变量、包管理。
- Python：脚本自动化、字节处理、网络请求、正则、文件解析。
- 计算机网络：TCP/IP、HTTP、DNS、TLS、代理。
- 数据结构：栈、队列、哈希表、树、图。
- 操作系统：进程、线程、虚拟内存、系统调用、文件系统。

推荐书籍：

- 《C 程序设计语言》：C 语言经典。
- 《深入理解计算机系统》：Pwn、Reverse、OS 基础核心书。
- 《鸟哥的 Linux 私房菜》：Linux 入门和日常使用。
- 《计算机网络：自顶向下方法》：网络和 Web 基础。
- 《Python Cookbook》：Python 工具脚本能力提升。

阶段验收：

- 能写 C 程序并用 gdb 调试。
- 能用 Python 处理 bytes、hex、base64、socket。
- 能解释一次 HTTP 请求从浏览器到服务器的大致过程。
- 能看懂 Linux 下 `strace`、`ltrace` 的基础输出。

### 阶段 2：CTF 基础能力

目标：每个方向都能独立做简单题。

训练内容：

- Misc：文件头、隐写、流量包、压缩包。
- Crypto：编码、XOR、RSA、AES、随机数。
- Web：抓包、SQL 注入、文件上传、命令执行。
- Reverse：Ghidra、字符串、简单算法还原。
- Pwn：栈溢出、ret2text、ret2libc。

阶段验收：

- 每个方向独立完成 20 道入门题。
- 每题写 writeup，总结识别点和关键命令。
- 能在比赛中快速判断一道题属于哪个知识点。

### 阶段 3：专项突破

目标：选 1-2 个主方向形成稳定拿分能力。

推荐组合：

- Web + Misc：适合快速参加比赛。
- Crypto + Reverse：适合数学/程序分析能力强的人。
- Reverse + Pwn：适合走二进制硬核路线。
- Web + Pwn：适合未来攻防/漏洞研究。

阶段验收：

- 主方向完成 100 道以上题。
- 能读懂中等难度题解并复现。
- 能把常见题型整理成自己的模板。

### 阶段 4：源码审计和漏洞原理

目标：不只会用 payload，而是理解漏洞产生原因。

训练内容：

- Web：PHP、Java、Python、Node.js 框架漏洞。
- Pwn：glibc malloc、动态链接、沙箱、ROP/SROP。
- Reverse：编译器优化、反调试、VM、混淆。
- Crypto：格攻击、椭圆曲线、协议漏洞。
- Misc：内存取证、磁盘取证、网络协议还原。

阶段验收：

- 能读源码定位漏洞点。
- 能把 CVE 漏洞复现成最小 demo。
- 能解释 payload 为什么有效。

### 阶段 5：比赛能力

目标：在真实比赛里稳定产出。

训练内容：

- 快速信息收集。
- 题目优先级判断。
- 多方向协作。
- 脚本模板化。
- 赛后复盘。

阶段验收：

- 能在 4-6 小时比赛中至少稳定解出基础题。
- 能在 24-48 小时比赛中持续推进中等题。
- 能写清楚赛后 writeup。

### 阶段 6：研究能力

目标：能研究新题型、新漏洞、新工具。

训练内容：

- 阅读英文论文。
- 阅读真实 CVE 分析。
- 阅读开源工具源码。
- 复现复杂漏洞链。
- 自己出题或改题。

推荐长期资源：

- CTFtime：跟踪国际比赛。
- PlaidCTF、DEF CON CTF、0CTF、HITCON、Google CTF、SECCON：高质量赛题。
- LiveOverflow：二进制和 Web 安全视频。
- pwn.college：系统化 Pwn 训练。
- PortSwigger Web Security Academy：系统化 Web 训练。
- CryptoHack：系统化 Crypto 训练。
- Project Zero Blog：真实漏洞研究。
- Trail of Bits Blog：工程化安全研究。

## 训练节奏建议

### 每日 1-2 小时

- 30 分钟读知识点或书。
- 60 分钟做题。
- 30 分钟写复盘。

### 每周

- 至少完成 5-10 道题。
- 至少复现 1 道看题解才会的题。
- 整理 1 个可复用脚本或模板。

### 每月

- 参加或虚拟参加 1 场比赛。
- 选 1 篇高质量 writeup 深度复现。
- 对一个方向做阶段总结。

## 硬核选手的标准

- 不是“收藏很多工具”，而是知道什么时候用哪个工具。
- 不是“背 payload”，而是能解释漏洞成因。
- 不是“看完题解”，而是能独立复现并改写。
- 不是“会做简单题”，而是遇到陌生题能拆解问题。
- 不是“只会打靶场”，而是有复盘、模板、知识库和长期积累。
