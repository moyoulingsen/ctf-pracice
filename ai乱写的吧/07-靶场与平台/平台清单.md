# CTF 靶场与平台清单

> 只在合法授权的 CTF 平台、靶场和比赛环境中练习，不要对真实网站、学校系统、公司系统或陌生 IP 做扫描和攻击测试。

## 入门推荐顺序

1. NSSCTF：题目新，国内 CTF 训练常用，适合长期刷题。
2. BUUCTF：经典题多，适合补基础。
3. 攻防世界 / XCTF：国内老牌平台，题型覆盖广。
4. CTFHub：Web 基础模块化训练很好。
5. picoCTF：国外入门友好，英文题面，适合练比赛阅读。
6. PortSwigger Web Security Academy：专门练 Web，质量很高。
7. CryptoHack：专门练密码学。
8. OverTheWire：专门练 Linux / Web / 基础安全思维。

## 按方向选择平台

### Web

优先顺序：

1. PortSwigger Web Security Academy
2. CTFHub
3. ctf.show
4. NSSCTF
5. BUUCTF

适合学习：

- HTTP 请求/响应
- Cookie / Session
- SQL 注入
- XSS
- SSRF
- 文件上传
- 命令执行
- 反序列化

### Crypto

优先顺序：

1. CryptoHack
2. picoCTF
3. NSSCTF
4. BUUCTF
5. 攻防世界

适合学习：

- 编码转换
- 古典密码
- RSA
- AES / DES
- 哈希
- 数论
- ECC 基础

### Reverse

优先顺序：

1. picoCTF
2. BUUCTF
3. NSSCTF
4. 攻防世界
5. Root-Me

适合学习：

- `strings`
- Ghidra 反编译
- 简单算法逆向
- 查壳和脱壳基础
- 动态调试

### Pwn

优先顺序：

1. picoCTF
2. BUUCTF
3. NSSCTF
4. 攻防世界
5. Root-Me

适合学习：

- C 语言漏洞
- 栈溢出
- 格式化字符串
- ret2text
- ret2shellcode
- ret2libc
- ROP

### Misc / Forensics

优先顺序：

1. picoCTF
2. BUUCTF
3. NSSCTF
4. Bugku
5. Wireshark 示例题 / Root-Me

适合学习：

- 文件类型识别
- 图片隐写
- 压缩包分析
- 流量包分析
- 内存取证基础
- 二维码/音频/视频隐写

## 建议账号命名

尽量统一使用一个 CTF ID，方便以后参加比赛和沉淀记录。例如：

```text
moyoulingsen
```
